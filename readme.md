# Capiclue · web app

> **Archived (2023).** A practice project from late 2022: a small social network built end to end. No longer maintained.

![Screenshot](https://jn-images.netlify.app/Captura%20de%20pantalla_20230103_051747.png)

The web app of Capiclue; the API is [capiclue-back](https://github.com/carlo-coding/capiclue-back).

## What is in it

- Sign-up and login with email or Google, profile and avatar editing.
- Posts with up to three images (compressed in the browser before upload) and an image carousel.
- Comments, favourites, friend requests and notifications.
- Real-time chat between friends over Socket.IO.
- Four feeds: newest, friends, popular and favourites, plus search.

## Stack

React · TypeScript · Vite · Redux Toolkit · Material UI · Socket.IO client · Formik and Yup
